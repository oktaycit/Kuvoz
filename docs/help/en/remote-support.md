# Remote Support Help

Remote support helps the technical team connect to the device when needed. Use it only when necessary.

## When To Use It

- Technical service needs to check the device
- A network or software issue needs remote review
- Authorized support staff asks for connection information

## How To Use It

1. Open the Remote Access page from the main screen.
2. Check that the connection is active.
3. Share the connection information on screen only with authorized support staff.
4. Turn sharing off when support is finished.

## Share With Support

- Clinic or device name
- A short description of the issue
- Any warning text shown on screen
- Device connection information shown on screen

## Important

- Do not share connection information in public channels.
- Do not give access to people you do not know.
- Keep remote access off after the support session is complete.
