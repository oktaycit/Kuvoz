# Settings and Profile Help

This page briefly explains device settings and clinic profile information.

## What Are Settings For?

The Settings page controls daily device behavior.

- Cooling and fan preferences
- Sensor availability
- AI module and data recording
- System update, rollback, and disk cleanup actions

## When Changing Settings

1. Change only the setting you need.
2. Check the value again before saving.
3. After saving, watch the expected behavior on the main screen.
4. Do not change settings you are unsure about without technical support.

## Profile Page

The Profile page stores clinic and authorized contact information.

- Clinic name and contact details
- Authorized person details
- Information that helps identify the device

Keeping this information current makes support faster.

## Disk Cleanup

Disk Cleanup removes unnecessary records and temporary files.

- The action cannot be undone.
- If older logs may be needed, ask technical support before cleanup.
- After cleanup, the device continues creating new records normally.

## Security

- Settings and profile changes should be made by authorized staff.
- Contact and access details must not be shared with unauthorized people.
- If clinical safety is affected, local clinic procedures come first.
