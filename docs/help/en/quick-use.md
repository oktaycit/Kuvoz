# Kuvoz Quick Use Help

This page is for daily use. Technical setup and service details are not shown in the operator help screen.

## Daily Start

1. Check that the device is powered on and the screen is working.
2. Confirm that temperature, humidity, and oxygen values are visible when available.
3. Before placing the patient inside, make sure the inner area is clean and safe.
4. Set target values according to the veterinarian's care plan.

## Main Screen

- Sensor cards show the current environment values.
- Control buttons manage lighting, humidity, heating, fan, and disinfection outputs.
- If you see a colored warning or an unexpected value, check the patient and the device.
- In uncertain situations, manual clinical control comes first.

## Changing Values

1. Adjust target temperature and humidity according to clinical need.
2. Check the value again before saving.
3. After saving, watch the device behavior on the main screen for a few minutes.

## AI and Charts

- AI screens help follow movement, general status, and historical trends.
- AI alerts are supportive only; they do not replace a veterinarian's assessment.
- Charts may not show a point for every second. The system summarizes meaningful changes.

## Life Cycle

- The Life Cycle screen is used to record observations such as eating, drinking, resting, and similar care notes.
- These records help make the care process easier to follow.

## Disinfection

- Start UV and ozone actions only according to the clinic's safety procedure.
- Do not leave the device and environment unattended during the process.
- If unsure, ask technical support or the responsible veterinarian.

## If There Is a Problem

1. Refresh the page.
2. Check power and network connection.
3. If sensor values are missing, wait a few minutes and check again.
4. If the issue continues, contact technical support.

## Safe Use

- The device should be used by trained clinical staff.
- Clinical decisions are always the veterinarian's responsibility.
- Share remote access details only with authorized support staff.
